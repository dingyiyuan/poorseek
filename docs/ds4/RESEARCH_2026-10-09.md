# Research 2026-10-09: Infernix, Strata 0.1.40/0.1.41, community reports - what DS4 can use

Sources: Infernix README + Flash-Next guide (github.com/Wallawalla47/Infernix, pushed 2026-10-09), upstream Strata
log a1641e9f..v0.1.41 (fb58e0db), r/Qwen_AI and r/LocalLLM threads Mal shared (UD-IQ4_XS on a 5090 laptop, Infernix
launch, "Strata next flash findings").  Infernix itself is RTX 50 only (sm_120a, NVFP4) - no use on the 4090 as an
engine; the value is its design choices.

## Ranked: what to take into DS4

1. **Rank-gated arena admission (Infernix SSD tier)** - "read experts that rank above the coldest RAM expert replace
   it", ranking seeded from saved usage counts.  Our `--arena-adapt` promotes on *first* NVMe read (pure LRU), the
   hysteresis gap s37 flagged: a one-off German token evicts an English expert.  Port: per-expert decayed hit count,
   promote only if count > coldest arena expert's.  Cheap, CPU-only to write; fixes the topic-switch thrash before
   the en->de->en test even runs.
2. **Persisted expert state / warm start (Infernix `.expert-state`)** - save which experts were hot + counts at exit
   (and every 10 min), next start seeds VRAM/RAM from it (+24% first-hundreds-of-tokens decode on a repeated task).
   We seed from a static `--profile ds4routes.bin`; with soft pruning the arena-adapt promotions are lost at exit.
   Write the adapted arena/VRAM set back as a profile.
3. **Elastic K/V (upstream `--kv-grow`, 9e3dbfe7)** - K/V and expert arena as CUDA VMM ranges; K/V maps 2 MiB chunks
   only for the cells reached, slots give way as context grows, short request hands them back.  No address moves, so
   CUDA graphs stay valid.  This is exactly the 250K-500K trade: today 256K costs ~330 slots up front (1818 vs ~2150).
   Port the idea to DS4's comp/icomp caches (core/vmm.hpp is ~230 lines, self-contained).
4. **KV streaming window (upstream `--kv-resident 32768`)** - explains the Reddit "keeps 32k in VRAM, rest in system
   RAM": QSA layers keep a 32K-cell VRAM window, the rest of K/V in pinned RAM.  Community 4090 + 32 GB RAM ran
   **512K context (YaRN 2) at 122 tok/s on Flash-Next IQ2_XS**.  Our `--comp-host` is the all-or-nothing version
   (~3 ms/token at 256K).  DS4 CSA only gathers top-512 compressed rows per token, so a recent-window-in-VRAM +
   sparse-gather-from-pinned-RAM split should cost far less than 3 ms.  Candidate for the 512K step.
5. **Adaptive MTP draft length (Infernix)** - each round drafts what recent acceptance justifies, down to zero, and
   verifies only drafts with drafter p >= 0.5 (upstream Strata has `--spec-min-p 0.5` too).  Our MTP verify loses
   (19-21 vs 24.9) at a flat 63% acceptance; gated drafting skips the rounds that lose.  Likely the cheapest route
   past 25 tok/s.
6. **File tier I/O (upstream 2d929a28, 805088d5, 073e2fe2)** - O_DIRECT + kernel async reads on Linux, batched reads
   of adjacent records (Infernix: coalesce up to 12-32 MiB).  Soft-pruned experts cost 6.6 ms/token from NVMe; sort a
   token's pruned-expert reads by file offset and issue them together.
7. **Foresight swap space (upstream 14f9e4c5, ef362cc4)** - per-layer VRAM slots refilled on their own stream with
   recently missed experts, fed by router look-ahead.  Overlaps our `--vram-lru` + `--pf-b`; read for comparison only.
8. **CPU expert workers: fewer is faster** (Infernix: 6 workers, more measured slower - CPU and PCIe share host memory
   bandwidth).  Matches our s12 DDR4 finding (29.9 GB/s CPU+PCIe total).  Worth one sweep of DS4's pool size.

Not for DS4 now: hybrid prefix cache / persisted prefix cache (serving), n-gram copy drafting (agentic serving),
route-resident experts (= our `--route-bias`, already measured lossy), stage pinning (upstream found it corrupts
IQ3_S decode after a long prompt - do NOT enable pinned stage buffers).

## Upstream sync

DS4's base `6f32ec0` (origin/main) has the same tree as upstream `a1641e9f`; the histories are unrelated (re-imported),
so `git merge` refuses.  `git merge-tree --merge-base=a1641e9f deepseek4 v0.1.41` = 8 conflicted files, 14 hunks:
CMakeLists.txt, README.md, src/kernels/cpu/{iq_avx2,native_expert,pool}.cpp, src/kernels/cuda/iq_kernels.cu,
src/prefill/moe_mmq.cu, tools/strata_tokenizer.py.  DS4 links native_expert/pool/iq_kernels/native_mmvq/moe_mmq, so
upstream's **q8_1 scale-clamp fixes (#606, #1448)** and **AVX2 Q8_K quantizer / AVX-VNNI i-quant rows** do reach DS4.
The expert-cache / foresight / kv-grow work is in the Qwen engine path DS4 does not run (port as ideas, above).
Worktree `~/AI/Strata-DS4-0141` (branch `ds4-on-0141`) is ready; merge recipe:
`git replace --graft 6f32ec0 a1641e9f && git merge --no-ff v0.1.41; git replace -d 6f32ec0` (resolve, rebuild,
p600 ppl gate vs 10.47 before switching builds).  Merge, not rebase: ds4/main is public.
